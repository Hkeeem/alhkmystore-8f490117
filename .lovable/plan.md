# ربط خريطة المتاجر والعروض الحقيقية

## النتيجة
- عرض مواقع المتاجر المحفوظة والموثقة فعليًا على الخريطة، بدل وضع العروض قرب مركز المدينة بصورة تقديرية.
- ربط كل موقع بالعروض النشطة الخاصة بمتجره، مع فتح تفاصيل العرض أو رابطه الصحيح.
- إبقاء أنواع الخريطة الثلاثة: العادية، القمر الصناعي، والتضاريس، مع تبديل طبقة واحدة دون تراكم.
- إظهار حالة واضحة عندما لا توجد مواقع موثقة، بدل دبابيس أو إحداثيات مصطنعة.

## التنفيذ
1. إضافة مصدر قراءة عام وآمن للفروع النشطة من قاعدة البيانات، بالحقول اللازمة فقط.
2. مطابقة عروض التجار المنشورة مع فروع المتجر باستخدام هوية المتجر الموثقة، لا اسم المدينة وحده.
3. إنشاء دبوس لكل فرع حقيقي، وتجميع عروض المتجر داخله عند وجود أكثر من عرض.
4. إبقاء عروض السوشال التي تحتوي إحداثيات محفوظة فقط، واستبعاد أي عرض بلا إحداثيات دقيقة.
5. تحديث البحث والتصفية والعدادات لتشمل المتاجر والعروض الظاهرة على الخريطة.
6. التحقق في المتصفح من التحميل الأولي، تبديل أنواع الخريطة، فتح الدبابيس، وعدم ظهور مواقع تخمينية.

## تفاصيل تقنية
- لن تُستخدم إزاحة حول مركز المدينة أو أي إحداثيات منشأة حسابيًا.
- ستظل قاعدة البيانات هي المصدر الوحيد للمواقع والعروض.
- إذا كانت بيانات الفروع الحالية فارغة، ستعمل الخريطة طبيعيًا وتعرض رسالة بأن إضافة المواقع الموثقة مطلوبة.
