# خطة تطوير حكيم AI — مراحل متسلسلة

النطاق المطلوب كبير جداً (لوحة Admin + 4 أدوار + عقارات + خرائط + ذكاء اقتصادي + كاش باك + إشعارات + Premium + إعادة تصميم كامل). تنفيذه دفعة واحدة يكسر المشروع الحالي. أقترح تقسيمه إلى **مراحل**، ونبدأ بالأولوية اللي أنت طلبتها في العنوان: **لوحة تحكم Admin**.

## المرحلة ١ (الآن) — لوحة تحكم Admin بأدوار

**قاعدة البيانات (Supabase):**
- توسيع enum `app_role` ليشمل: `super_admin`, `admin`, `support`, `content_manager`, `user`
- جدول `complaints` (شكاوى المستخدمين)
- جدول `suggestions` (اقتراحات)
- جدول `premium_subscriptions` (خطة، حالة، تواريخ)
- جدول `admin_audit_log` (سجل عمليات المسؤولين)
- توسيع جدول `notifications` ببث جماعي (broadcast)
- سياسات RLS: كل جدول محمي بـ `has_role()` للأدوار المناسبة
- GRANTs كاملة لكل جدول

**واجهة `/admin`:**
- Layout جانبي (Sidebar) مع حماية عبر `_authenticated` + فحص الدور
- Dashboard: إحصائيات عامة (مستخدمين، عروض، شكاوى مفتوحة، اشتراكات)
- **إدارة العروض**: قائمة/إضافة/تعديل/حذف (deals من `src/data/deals.ts` → نقلها إلى جدول DB)
- **إدارة المتاجر**: CRUD
- **إدارة المستخدمين**: عرض + تعيين أدوار (Super Admin فقط)
- **الشكاوى**: قائمة + رد + إغلاق (Support + Admin)
- **الاقتراحات**: قائمة + وسم (Content Manager + Admin)
- **التقارير & Analytics**: رسوم بيانية (Recharts) لأكثر العروض مشاهدة، تحويلات، نمو المستخدمين
- **الإشعارات**: إرسال إشعار جماعي أو لمستخدم
- **اشتراكات Premium**: عرض/تعديل/إلغاء

**صلاحيات الأدوار:**
| القسم | Super Admin | Admin | Support | Content Manager |
|---|---|---|---|---|
| Dashboard | ✅ | ✅ | ✅ | ✅ |
| المستخدمون + الأدوار | ✅ | 👁️ | ❌ | ❌ |
| العروض/المتاجر | ✅ | ✅ | ❌ | ✅ |
| الشكاوى | ✅ | ✅ | ✅ | ❌ |
| الاقتراحات | ✅ | ✅ | 👁️ | ✅ |
| Analytics | ✅ | ✅ | 👁️ | 👁️ |
| الإشعارات | ✅ | ✅ | ❌ | ✅ |
| Premium | ✅ | ✅ | 👁️ | ❌ |

**server functions** جديدة تحت `src/lib/admin.functions.ts` مع `requireSupabaseAuth` + فحص دور داخل الـ handler.

## المراحل التالية (بعد اعتماد المرحلة ١)

- **مرحلة ٢**: Cashback + مفضلة + تنبيهات السعر (يستخدم جداول جديدة + Realtime)
- **مرحلة ٣**: قسم العقارات الكامل (جدول properties + خريطة + تحليل AI)
- **مرحلة ٤**: الذكاء الاقتصادي (Dashboard مؤشرات: ذهب/نفط/دولار — API خارجي)
- **مرحلة ٥**: تحسين الخرائط + Google Maps تكامل عميق
- **مرحلة ٦**: إعادة صقل الهوية البصرية النهائية + PWA + أداء

## ملاحظات مهمة

- **لن أحذف** أي صفحة أو وظيفة موجودة.
- **لن أستبدل** Supabase أو نظام Auth.
- المرحلة ١ فقط تضيف جداول جديدة + مسار `/admin` جديد.
- بعد ما ننهي المرحلة ١ ونتأكد إنها شغالة، ننتقل للمرحلة اللي بعدها.
